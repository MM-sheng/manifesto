# 新未来主义宣言

[English](README.md)

未来不会自己到来。它是被人做出来的。

今天，大部分的未来是在少数几家公司里被决定的。它们决定你用什么工具，你的数据去哪里，你能做什么、不能做什么。大多数人在等，等别人把未来造好，再递到自己手里。

我们不等。

我们相信，未来属于愿意亲手发明它的人。一个人，一台电脑，一个周末，就足以做出一件以前不存在的东西。PGP 是一个人写的。比特币最初只是九页纸和一段程序。改变世界的东西，开始的时候都很小。

我们不求许可。一件东西应该存在，我们就把它做出来。

我们相信知识应该自由流通。做出来的东西拿出来给人看，让别人能学、能改、能接着往下做。

我们站在个人这一边。一百年前，最早的未来主义者崇拜机器，也崇拜机器背后的权力。新未来主义把机器交到个人手里。好的工具让用它的人更有能力、更自主，而不是更依赖某个平台。

我们同样看重思想。把一个问题想透，写成别人可以接着做的样子，也是创造。

谈论未来的人很多，动手的人很少。我们找的是后一种。

这一切现在还不存在。只有这篇宣言和一间空屋子。如果你正在做点什么，不管它多小、多粗糙，把它带来，一起决定这里会成为什么。

我们在找创造未来的人。我们把这叫作新未来主义。如果这说的是你，来。

—— Mario sheng，2026 年 10 月
